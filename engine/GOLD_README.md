# 黄金数据与趋势强度策略信号

本目录由 GitHub Actions 每周六自动更新，产出黄金 K 线数据与策略周度信号。

## 策略：GOLD-TS-16/40

趋势强度型周频择时。**每周五收盘计算，下周一开盘执行**，剩余资金买货币基金。

```
MA16  = 最近 16 周收盘均价
MA40  = 最近 40 周收盘均价
ATR10 = 最近 10 周真实波幅均值

S = (MA16 - MA40) / ATR10          趋势强度，无量纲
B = clip(0.75 × S, 0, 1)           基础仓位（无基础仓位，趋势转空即空仓）
V = min(1, 2.5% / ATR%)            波动系数，只减仓不加仓
P = B × V                          目标黄金仓位
```

与原方案（20/50/ATR20、base 0.5、调仓阈值 5%）的三处关键差异：

1. **`base = 0`** — 趋势转空时彻底空仓，不死守 50%。这是影响最大的一项。
2. **调仓阈值 = 0** — 每周如实调仓，仓位严格等于目标值。其作用是消除跟踪误差，不是收益来源。
3. **ATR 周期 = 10 周** — 用更快的波动度量缩放仓位，价值体现在平均回撤（3.13% → 2.65%）。

## 自动化

`.github/workflows/gold.yml` — 每周六 10:20（北京时间）运行，也支持手动触发。

```
fetch_gold.py  ->  抓数据 + 质量校验 + 落 parquet
gold_signal.py ->  算信号 + 回测 + 写简报
gold_check.py  ->  硬门禁：参数锁定 / 指标重算 / P=B×V 复核 / 回撤告警
```

无数据变更时自动跳过 commit，不产生噪音提交。

### 为什么要 gold_check.py 这道门禁

历史上最容易出错的不是抓取，而是**悄悄改口径**。`gold_check.py` 锁死四件事：

1. 参数必须等于 16/40/10/0.75/0/2.5%（改动需先重跑离线回测并更新说明书）
2. 用原始 OHLC 重算 MA16/MA40/ATR10，与落盘值比对
3. 复核最新一周 `P = B × V`
4. 回撤超出 -15% 时告警

特别地，**执行价必须是次周开盘**：用当周开盘属于前视偏差（周五收盘才知道信号，却能回到本周开盘成交），
会把年化从 9.4% 虚高到 10.8%、夏普从 0.88 虚高到 1.09。

### 已知数据瑕疵

- **XAU 有约 2.5% 的行（132/5185）high/low 与 open/close 相差约 1%**，集中在 2012-2020，是新浪全球期货线的源瑕疵。
  已验证对策略**零影响**：策略的 TR = max(H−L, |H−昨收|, |L−昨收|) 对此有容错，
  1004 周目标仓位序列在修正前后完全一致（最大差 0.000000）。
- 日历上存在 >10 天的缺口，属节假日停市，正常。

## 风险提示

年化 9.40% 低于买入持有黄金的 10.10%，策略价值全部体现在风险调整后（最大回撤只有买入持有 43.50% 的约 1/3.5，夏普 1.9 倍）。

- **2016-2019 震荡市年化仅 4.6%**，同期买入持有 9.6%。这是趋势策略的固有短板，
  已测试动态波动目标、杠杆、长周期过滤、绝对动量、不对称斜率五种增强，均无法改善。
- **无止损机制**，靠趋势反转自然减仓。遇跳空（2020-03、2013-04）实际回撤可能超 -12.51%。
- 标的差异：ETF 有跟踪误差、期货有展期成本、积存金有买卖价差，实际收益会低于回测。
- 以上为历史回测与规则计算结果，不构成投资建议。
